# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.x (current) | ✅ |

## Reporting a vulnerability

**Please do not file a public GitHub issue for security vulnerabilities.**

Report security issues by emailing **security@your-org.example.com** with the
subject line `[hiero-sdk-utils] Security vulnerability`.

Include:

- A description of the vulnerability and its impact.
- Steps to reproduce or a proof-of-concept.
- Any suggested mitigations.

We will acknowledge receipt within **48 hours** and aim to release a patch
within **14 days** for confirmed critical issues.

We follow responsible disclosure: we will coordinate a public disclosure date
with you and credit you in the release notes (unless you prefer to remain
anonymous).
